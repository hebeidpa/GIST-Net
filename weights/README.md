# Frozen weights

The release assets contain exactly one frozen checkpoint for each pipeline stage:

- `gist_net_stage1.pt`
- `gist_net_stage2.pt`

Download both files from the latest GitHub Release and place them in this directory. Confirm file integrity with:

```bash
sha256sum -c SHA256SUMS
```

The Merlin foundation-model checkpoint is governed by its upstream distribution terms and is not redistributed here.
